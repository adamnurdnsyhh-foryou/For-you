# Secret Message Website 🌸

File:
- index.html = halaman website
- style.css = tampilan
- script.js = kata sandi dan fungsi buka pesan

## Mengubah password
Buka `script.js`, lalu cari:

const PASSWORD = "bunga";

Ganti `bunga` dengan password yang kamu inginkan.

## Mengubah isi pesan
Buka `index.html` dan cari bagian di dalam:

<div class="message">
...
</div>

Ganti teksnya dengan pesanmu sendiri.

## Mengganti emoji bunga dengan gambar
Kamu bisa mengganti:
<div class="flower">🌸</div>

menjadi:
<img class="flower-image" src="flower.jpg" alt="Bunga">

Lalu masukkan file `flower.jpg` ke folder yang sama.
